# LR1 Camera System

| | |
|---|---|
| **Description** | 61MP camera system for mapping and inspections |
| **Compatibility** | Astro ✓ |
| **Weight** | 970g (with default lens) |
| **NDAA Compliant** | No |
| **Offered By** | Freefly |

{% embed url="https://www.youtube.com/watch?v=ycIz4kCDKPQ" %}

The LR1 Payload is a next generation high resolution payload using the Sony ILX-LR1 camera, integrated into a Freefly mini gimbal.

The 61 megapixel image resolution is ideal for mapping and inspections, and the gimbal provides expansion ports for other sensors, allowing the payload to work for a wide range of use-cases. It ships with a 24 mm lens, and [several other lenses](lr1-lenses-and-expansion/) are supported.
