# Warranty

Freefly SL batteries are covered by Freefly's warranty for 1 year or 500 cycles (whichever happens first).&#x20;

The warranty covers:

* Manufacturing defects
* Functionality failures
  * Does not charge/discharge
  * Screen does not work
  * Displays permanent Error Code
  * Displays repeated Error Code under normal usage

Warranty is void if any of the following criteria are exceeded:

| Maximum Battery Cycles        | Greater than 500 cycles                                                             |
| ----------------------------- | ----------------------------------------------------------------------------------- |
| Date of Purchase              | More than 1 year from date of purchase                                              |
| Minimum Operation Temperature | Lower than -20 degrees Celsius                                                      |
| Minimum Battery Voltage       | Lower than 15 Volts                                                                 |
| Maximum Discharge Rate        | <p>> 83A on SL8-Air  </p><p>> 28A on SL4-Ground</p>                                 |
| Maximum Charge Rate           | <p>Greater than 1.5 C </p><p></p><p>> 12A on SL8-Air</p><p>> 6.8A on SL4-Ground</p> |

[Contact Freefly Support](https://freeflysystems.com/contact) with any questions or warranty claims.
