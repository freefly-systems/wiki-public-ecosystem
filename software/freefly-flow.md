# Freefly Flow

Freefly Flow is Freefly's iPad app for processing and visualizing LiDAR data. Process scans in the field, explore point clouds, and export industry-standard formats.

## Download

Freefly Flow is available on the App Store for iPad.

{% hint style="info" %}
**System Requirements**

* iPad with iPadOS 18 or later
* App version 3.0 or later recommended
{% endhint %}

## Key Features

* **Project Management** - Create and organize LiDAR projects with over 6,500 coordinate reference systems supported
* **GNSS Post-Processing** - PPK processing with base station correction data
* **Point Cloud Visualization** - Explore billions of points with gesture-based navigation
* **Export Options** - Export to LAS or compressed LAZ formats with configurable point density
