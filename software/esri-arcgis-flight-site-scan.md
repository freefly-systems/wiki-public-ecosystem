# ESRI ArcGIS Flight / Site Scan

Astro and Alta X Gen2 are tightly integrated with ESRI's ArcGIS Flight (formerly Site Scan), a professional drone mapping and analytics platform. This integration enables an end-to-end mapping workflow from flight planning through data processing.

{% hint style="info" %}
ArcGIS Flight is an ESRI product. Visit [ESRI's ArcGIS Flight page](https://www.esri.com/en-us/arcgis/products/arcgis-flight/overview) for product information, pricing, and support.
{% endhint %}

## Integration Features

* **Direct aircraft support** - ArcGIS Flight recognizes Astro and Alta X Gen2 as supported aircraft
* **iPad connectivity** - Connect via Pilot Pro's RJ-45 ethernet port for field use
* **PPK-ready** - Process high-accuracy geotagged photos from mapping workflows
